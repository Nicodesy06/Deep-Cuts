# Scope

Deep Cuts is a **library intelligence** application: manage, analyse, organise, discover and prepare.

## In scope

Audio preview (incl. hot-region / intro / outro), waveform, cue points, beatgrid, BPM and key analysis,
harmonic compatibility, phrase/structure detection, playlist sequencing, set preparation (chapters,
next-track suggestions, energy progression, transition *compatibility* suggestions), matching tracks,
export of playlists and metadata, Rekordbox preparation and interoperability with other DJ software.

## Explicitly out of scope (not planned, not in the UI)

Mix Studio · multitrack DAW editor · mix timelines · recording DJ mixes · rendering continuous mixes ·
video editing/rendering · VST/AU hosting · production FX chains · EQ/crossfader automation · mashup
editor · stem separation for remixes/mashups · Ableton project export · live DJ performance · MIDI
controller mixing · CDJ emulation · virtual mixer.

"Preparing a set" means selecting and ordering tracks. It never means producing the audio of the set.
Adding any excluded item requires an explicit new request.
